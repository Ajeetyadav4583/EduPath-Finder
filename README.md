# EduPath Finder

EduPath Finder is a modern educational web platform built using Flask, HTML, and CSS. It helps students explore learning paths in Python, AI/ML, Web Development, UPSC, and JEE through a clean and responsive user interface.

## Features
- Responsive UI
- Course Categories
- Modern Design
- Flask Backend
- Live Deployment on Render

## Tech Stack
- Python
- Flask
- HTML
- CSS
